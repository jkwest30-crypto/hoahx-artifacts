Packages

Features that share a subject and the same part of the platform, built together from one brief on one branch with one round of testing. A package costs less than its features apart, and its features are counted once.

Listed in build order: the sequence the architecture asks for. Add a package to keep it in the launch; the running total at the foot of the page shows the hours, the date, and the cost.

Must follow names what has to be in place before a package is built; Runs beside names what can be built at the same time. Hours are the build estimates for this engagement. Adding a package here and one of its features on the Features page counts the feature once.
