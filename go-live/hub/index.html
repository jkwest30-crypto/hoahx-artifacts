Who can open a document. A link opens the document in Google Drive, so only people it is shared with can read it. This page holds links and one-line descriptions, never the documents themselves.

To add a document. Put it, or a shortcut to it, in the matching folder of the shared Drive folder: Product, then Pricing, for a pricing document. It appears here within a few minutes, under the name the file has. Rename or move the file and this page follows. A new folder inside a section becomes a new group.

To add a web address. Add a row to the sheet named Hub links in the same Drive folder: the section, the group, a title, the link, and a line about it.
